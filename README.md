# 🎮 Pong Clone

My first game project — a **Pong clone built with Unity**.  
I created this project to learn the fundamentals of game development, such as physics, UI, and game flow.  
Players can customize **ball speed**, **paddle speed**, and **points to win** before starting a match.

You can play **1v1** (local multiplayer) or **against the computer**.

---

## 🕹️ Controls

| Player | Action | Key |
|:-------:|:--------|:----|
| Player 1 | Move Up | **W** |
| Player 1 | Move Down | **S** |
| Player 2 | Move Up | **Up Arrow (↑)** |
| Player 2 | Move Down | **Down Arrow (↓)** |
| Both | Pause / Resume | **Esc** |

---

## ⚙️ Features
- Adjustable game settings (speed and points to win)  
- Play against another player or the computer  
- Simple UI menus (Play, Pause, and Game Over)  
- Basic score system and win condition  

---

## ▶️ How to Play
1. Go to the folder **`Game`**  
2. Run the **`Pong.exe`** file  
3. Adjust the settings, start the match, and have fun!
